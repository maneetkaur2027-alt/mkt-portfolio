# MKT — Maneet Kaur Tandon
A scrapbook-style personal portfolio built as a self-contained static website.

## Run locally
Open `index.html` in a browser, or use a simple local server:
`python3 -m http.server 8000`

## Deploy
Upload this folder to GitHub and import the repository into Vercel. No build command is required for this static version.

## Replace assets
All media lives in `assets/`. The HTML currently references the supplied assets by generated `asset-XX` names. `asset-map.json` records the original uploaded filenames.
